Modules

Three languages, one learning path.

Each module moves from basic to intermediate topics, with examples, a short video and a quiz.

H

HTML — structure

How web content is organized.

  • Page structure and headings
  • Paragraphs, links and images
  • Lists and tables
  • Forms and inputs
C

CSS — presentation

How web content looks.

  • Selectors, colors and fonts
  • The box model and spacing
  • Flexbox layouts
  • Hover effects and transitions
J

Java — logic

How programs think and act.

  • Variables and data types
  • Input and output
  • Conditions and loops
  • Methods and simple classes

Topic lists above are an overview of the planned module scope. Final lesson content follows the competencies in the assessment instrument.
